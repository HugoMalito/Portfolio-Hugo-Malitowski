Projet site web dynamique

J’ai conçu un site web dynamique en HTML, CSS et PHP dans un délai court. Le défi consistait à proposer un contenu renouvelé chaque jour sans base de données, en garantissant une navigation fluide. Ce projet m’a permis de développer mon autonomie, ma rigueur et ma capacité à livrer un résultat fonctionnel rapidement.

Le thème de ce site est un horoscope. Par conséquent, celui-ci doit se renouveler chaque jour.
